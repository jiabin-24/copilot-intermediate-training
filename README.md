# GitHub Copilot 中級培訓儲存庫

## 簡介

### :bulb: 本儲存庫旨在協助工程師和培訓講師進行 **GitHub Copilot 中級培訓示範**。其中包含的練習用於展示 Copilot 和 Copilot Chat 如何在真實情境中顯著改善開發工作流程。

無論你是負責組織培訓的講師，還是參與培訓的工程師，本儲存庫都提供了有效使用 Copilot 和 Copilot Chat 所需的教材和指引。

---

## 概述

GitHub Copilot 是一款功能強大的工具，它能夠提供感知內容的程式碼建議，並透過 Copilot Chat 提供互動式協助，從而簡化編碼過程。然而，要真正發揮它的潛力，關鍵在於如何有效地與它**互動並給予指引**。

本儲存庫涵蓋：
- 展示 Copilot 和 Copilot Chat 優勢的**真實情境**。
- 聚焦儲存庫分析、改進建議和工作量（LOE）估算的**實作示範**。
- 協助講師進行有意義且具影響力之示範的技巧。

本儲存庫分為多個獨立練習，分別展示 Copilot 和 Copilot Chat 的特定使用情境，為參與者提供沉浸式、實務性的學習體驗。

---

## 本儲存庫的目標

完成本次培訓後，參與者將能夠：
- 更深入地理解 **GitHub Copilot** 和 **Copilot Chat** 的工作流程。
- 探索如何利用**提示詞工程**有效引導 Copilot。
- 學習如何評估程式碼庫、增強功能以及估算開發工作量。
- 建立運用 Copilot 處理複雜真實任務的信心。

對於培訓講師，本儲存庫提供了結構化指引，協助你**進行引人入勝的示範**，展現 Copilot 帶來的價值。

---

## 先決條件

開始之前，請確保具備以下條件：
- **GitHub 帳戶**：用於存取儲存庫和啟用 Copilot。
- **Visual Studio Code**：本次工作坊使用的 IDE。
- **GitHub Copilot 和 Copilot Chat 擴充功能**：已在 VS Code 中安裝並啟用。
- 熟悉包括 GitHub 和 VS Code 在內的基本開發工作流程。

---

## 開始使用

1. 複製本儲存庫：
   ```bash
   git clone https://github.com/your-organization/copilot-intermediate-training.git
   cd copilot-intermediate-training
   ```
2. 閱讀每個示範的 README 以開始操作：
   - 示範 1 說明
   - 示範 2 說明
3. 設定開發環境：
   - 確保已在 VS Code 中啟用 Copilot 和 Copilot Chat。
   - 熟悉 VS Code 中的進階設定（具體步驟請參閱示範 1）。

## 培訓講師最佳實務

### :star2: 進行高效示範的技巧
- **提前準備**：熟悉示範內容，並確保所有工具均已正確設定。
- **鼓勵聽眾參與**：鼓勵參與者提問，並使用自己的環境同步操作。
- **充分利用 Copilot Chat**：使用 Copilot Chat 展示如何透過互動式提示詞最佳化和改進建議。
- **反覆改進和調整**：展示如何改進提示詞以提升 Copilot 的輸出品質。
